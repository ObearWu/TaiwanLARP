## English

The frontend for *Where to Play LARP in Taiwan* ("臺灣劇本殺哪裡玩？"), including the public site and the admin page.

URL: `https://obearwu.github.io/TaiwanLARP/`

Backed by the API in `ObearWu/TaiwanLARP-backend` (a Private repo).

Deployed via GitHub Pages from this repo's root.

For technical details and architecture decisions, see the full project report in `TaiwanLARP-backend`.
